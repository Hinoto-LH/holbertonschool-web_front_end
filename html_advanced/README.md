# Techium

Un projet de développement web pour les pages web de la société Techium, construit avec du HTML conforme W3C.

## Prérequis

- Tout le code HTML est conforme W3C et validé avec [W3C Validator](https://validator.w3.org/)
- `Techium` est le nom de la société utilisé sur toutes les pages web

|---------|-------------|
| `index.html` | Page web principale |
